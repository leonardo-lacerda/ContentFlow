# Subfase 2.1 — Wizard de Onboarding URL → Primeiro Carrossel

> **For Hermes:** Use subagent-driven-development skill to implement this plan.

**Goal:** Criar um wizard de onboarding que guia o usuario de uma URL ate o primeiro carrossel gerado, usando o novo sistema de BrandProfile.

**Architecture:** Novo componente `OnboardingWizard` com 5 etapas recuperaveis, usando os endpoints de brands, DNA extraction, AI ideas e carousel projects que ja existem no backend.

**Tech Stack:** Next.js, React, SWR, Tailwind CSS, lucide-react

---

## Etapas do Wizard

1. **Criar Marca** — Nome + URL + industria (opcional)
2. **Analisar Site** — Roda Brand DNA extraction, mostra loading
3. **Revisar DNA** — Mostra resumo, voz, publico, oferta, visual para edicao
4. **Gerar Ideias** — Gera lote de 10 ideias, usuario aprova uma
5. **Primeiro Carrossel** — Redireciona para o studio com a ideia selecionada

---

## Task 1: Criar componente OnboardingWizard

**Objective:** Criar o componente principal do wizard com 5 etapas

**Files:**
- Create: `./apps/frontend/src/components/onboarding/onboarding-wizard.component.tsx`

**Step 1: Create the wizard component**

The wizard manages state across 5 steps. Each step is a sub-component or inline render.

```typescript
// State managed by the wizard:
// - step: number (0-4)
// - brandName: string
// - brandWebsite: string  
// - brandIndustry: string
// - brandId: string (set after creation)
// - analyzing: boolean
// - dna: BrandDnaSnapshot | null
// - ideas: ContentIdea[]
// - selectedIdeaId: string | null
// - error: string
// - loading: boolean
```

**Step 2: Implement Step 1 — Create Brand**

Simple form: name (required), website (optional), industry (optional).
On submit: call `createBrand()`, then `selectBrand()`, save brandId, go to step 2.

**Step 3: Implement Step 2 — Analyze Site**

If website provided: call `analyzeBrand(brandId, url)`, poll `getLatestDna(brandId)` until status is not ANALYZING.
If no website: skip to manual DNA creation (step 3 with empty fields).

Show loading spinner with progress message.

**Step 4: Implement Step 3 — Review DNA**

Display the DNA snapshot in editable sections (summary, voice, audience, offer, visual, constraints).
Allow user to edit fields and save via `createDnaSnapshot()`.
When user clicks "Avançar", mark brand as ACTIVE (call selectBrand if needed).

**Step 5: Implement Step 4 — Generate Ideas**

Call AI generate ideas endpoint (`POST /ai-generate/carousel-ideas` with brandProfileId).
Then persist each idea via `POST /content-ideas`.
Show ideas as a list of cards (simplified swipe).
User selects one idea.

**Step 6: Implement Step 5 — First Carousel**

Call `createFromIdea(selectedIdeaId)` to create a CarouselProject.
Redirect to `/ai-generate-images` with the project loaded.
