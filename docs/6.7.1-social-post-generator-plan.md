# Fase 6.7.1 — Social Post Generator: Implementation Plan

> **Goal:** Generate platform-specific social media posts (Instagram, LinkedIn, TikTok, X/Twitter) from Brand DNA + a Content Idea or Carousel Project. Posts are created as drafts in the `/launches` area (Post model).

---

## 1. Architecture Decision: Reuse `Post` Model (No New Model)

The existing `Post` model already supports the `/launches` workflow with `state`, `content`, `integrationId`, `carouselProjectId`, and approval flow (`approvedSubmitForOrder`). Rather than creating a separate `SocialPost` model, we **extend the generation pipeline** to produce `Post` records directly, linked back to the source (ContentIdea or CarouselProject).

**Key insight:** The `Post` model already has:
- `content` (String) — the post text
- `integrationId` — links to a platform integration
- `carouselProjectId` — optional link to a carousel
- `state` (State enum: QUEUE, etc.) — for scheduling
- `title`, `description` — for metadata

We add:
- `socialPostMetadata` (Json?) — stores platform-specific data (char count, hashtags, CTA, tone used)
- A new `contentIdeaId` (String?) field to link posts back to their source idea

### 5.1 Zod Schema: `social-post.schema.ts`

```typescript
import { z } from 'zod';

export const VERSION = '1.0.0';

const PlatformConfig = z.object({
  platform: z.enum(['instagram', 'linkedin', 'tiktok', 'twitter', 'threads', 'facebook']),
  maxChars: z.number(),
  hashtagLimit: z.number(),
});

const SocialPostSchema = z.object({
  platform: z.string().describe('Target platform'),
  content: z.string().describe('The full post text (including hashtags if platform-appropriate)'),
  caption: z.string().optional().describe('Separate caption (Instagram/TikTok)'),
  hashtags: z.array(z.string()).default([]).describe('Relevant hashtags'),
  cta: z.string().optional().describe('Call-to-action text'),
  tone: z.string().describe('Tone used for this platform'),
  charCount: z.number().describe('Character count of the main content'),
  notes: z.string().optional().describe('Internal notes about platform-specific adaptations'),
});

export const SocialPostBatchSchema = z.object({
  posts: z.array(SocialPostSchema).min(1).describe('Generated posts for each target platform'),
});

export type SocialPost = z.infer<typeof SocialPostSchema>;
export type SocialPostBatch = z.infer<typeof SocialPostBatchSchema>;

// Platform constraints
export const PLATFORM_CONSTRAINTS: Record<string, { maxChars: number; hashtagLimit: number; tone: string }> = {
  instagram: { maxChars: 2200, hashtagLimit: 30, tone: 'conversational, emoji-rich, visual storytelling' },
  linkedin:  { maxChars: 3000, hashtagLimit: 5,  tone: 'professional, thought-leadership, value-driven' },
  tiktok:    { maxChars: 2200, hashtagLimit: 8,  tone: 'casual, trend-aware, playful, authentic' },
  twitter:   { maxChars: 280,  hashtagLimit: 5,  tone: 'concise, punchy, witty, direct' },
  threads:   { maxChars: 500,  hashtagLimit: 5,  tone: 'conversational, authentic, raw' },
  facebook:  { maxChars: 63206, hashtagLimit: 3, tone: 'friendly, story-driven, community-focused' },
};

export function validate(data: unknown) {
  const result = SocialPostBatchSchema.safeParse(data);
  if (result.success) return { success: true, data: result.data, errors: null };
  return { success: false, data: null, errors: result.error };
}

export function parse(data: unknown): SocialPostBatch {
  return SocialPostBatchSchema.parse(data);
}
```

### 5.4 Social Post Generate Service

```typescript
// libraries/nestjs-libraries/src/ai-generate/social-post-generate.service.ts

@Injectable()
export class SocialPostGenerateService {
  constructor(
    private brandProfileService: BrandProfileService,
    private contentIdeaService: ContentIdeaService,
    private carouselProjectService: CarouselProjectService,
    private generationJobService: GenerationJobService,
    private postsService: PostsService,  // existing
  ) {}

  async generateSocialPosts(orgId: string, dto: GenerateSocialPostsDto): Promise<SocialPostBatch> {
    // 1. Validate brand ownership
    await this.brandProfileService.validateBrandOwnership(orgId, dto.brandProfileId);

    // 2. Load Brand DNA
    const brand = await this.brandProfileService.getBrand(dto.brandProfileId);
    const dna = await this.brandProfileService.getLatestDnaSnapshot(dto.brandProfileId);

    // 3. Load source content (idea or carousel)
    let sourceContent: { title: string; hook: string; goal: string; angle: string; slides?: any };
    if (dto.contentIdeaId) {
      const idea = await this.contentIdeaService.getIdea(dto.contentIdeaId);
      sourceContent = { title: idea.title, hook: idea.hook, goal: idea.goal, angle: idea.angle };
    } else if (dto.carouselProjectId) {
      const project = await this.carouselProjectService.getProject(dto.carouselProjectId);
      sourceContent = { title: project.title, hook: '', goal: '', angle: project.caption || '', slides: project.slides };
    } else {
      throw new Error('Either contentIdeaId or carouselProjectId must be provided');
    }

    // 4. Create generation job
    const job = await this.generationJobService.createJob({
      organizationId: orgId,
      brandProfileId: dto.brandProfileId,
      type: 'SOCIAL_POST_GENERATION',
      model: 'gpt-4.1',
      provider: 'openai',
      promptVersion: '1.0.0',
      schemaVersion: '1.0.0',
    });

    try {
      await this.generationJobService.startJob(job.id);

      // 5. Build prompt with Brand DNA context
      const prompt = this.buildPrompt(dna, sourceContent, dto.platforms, dto.additionalContext);

      // 6. Call OpenAI with structured output
      const rawResponse = await openai.chat.completions.parse({
        model: 'gpt-4.1',
        messages: [
          { role: 'system', content: SYSTEM_PROMPT },
          { role: 'user', content: prompt },
        ],
        response_format: zodResponseFormat(SocialPostBatchSchema, 'socialPosts'),
      });

      const parsed = rawResponse.choices[0].message.parsed;
      if (!parsed) throw new Error('Failed to parse AI response');

      // 7. Validate with schema
      const validation = validateAiResponse('social-post', JSON.stringify(parsed));
      if (!validation.success) throw new Error('AI response validation failed');

      // 8. Complete job
      await this.generationJobService.completeJob(job.id, validation.data);

      return validation.data as SocialPostBatch;
    } catch (error) {
      await this.generationJobService.failJob(job.id, error.message);
      throw error;
    }
  }

  async createDraftPosts(
    orgId: string,
    socialPosts: SocialPostBatch,
    source: { contentIdeaId?: string; carouselProjectId?: string; brandProfileId: string }
  ): Promise<Post[]> {
    // Creates Post records in the launches area
    const posts = [];
    for (const sp of socialPosts.posts) {
      const post = await this.postsService.createPost({
        organizationId: orgId,
        content: sp.content,
        title: `${sp.platform} - ${source.contentIdeaId ? 'From Idea' : 'From Carousel'}`,
        socialPostMetadata: {
          platform: sp.platform,
          charCount: sp.charCount,
          hashtags: sp.hashtags,
          cta: sp.cta,
          tone: sp.tone,
          notes: sp.notes,
        },
        contentIdeaId: source.contentIdeaId,
        carouselProjectId: source.carouselProjectId,
        state: 'QUEUE',
      });
      posts.push(post);
    }
    return posts;
  }
}
```

### 5.5 Backend Controller: `social-posts.controller.ts`

```typescript
@ApiTags('Social Posts')
@Controller('/social-posts')
export class SocialPostsController {
  constructor(
    private socialPostGenerateService: SocialPostGenerateService,
    private brandProfileService: BrandProfileService,
  ) {}

  // Generate social posts (AI)
  @Post('/generate')
  @CheckPolicies([AuthorizationActions.Create, Sections.ADMIN])
  async generatePosts(
    @GetOrgFromRequest() org: Organization,
    @Body() body: GenerateSocialPostsDto
  ) {
    return this.socialPostGenerateService.generateSocialPosts(org.id, body);
  }

  // Create draft posts in /launches from generated content
  @Post('/create-drafts')
  @CheckPolicies([AuthorizationActions.Create, Sections.ADMIN])
  async createDraftPosts(
    @GetOrgFromRequest() org: Organization,
    @Body() body: {
      socialPosts: SocialPostBatch;
      contentIdeaId?: string;
      carouselProjectId?: string;
      brandProfileId: string;
    }
  ) {
    return this.socialPostGenerateService.createDraftPosts(org.id, body.socialPosts, {
      contentIdeaId: body.contentIdeaId,
      carouselProjectId: body.carouselProjectId,
      brandProfileId: body.brandProfileId,
    });
  }

  // Get social posts generated from a specific idea
  @Get('/from-idea/:ideaId')
  async getPostsFromIdea(@Param('ideaId') ideaId: string) {
    return this.socialPostGenerateService.getPostsByContentIdea(ideaId);
  }

  // Get social posts generated from a specific carousel
  @Get('/from-carousel/:carouselId')
  async getPostsFromCarousel(@Param('carouselId') carouselId: string) {
    return this.socialPostGenerateService.getPostsByCarouselProject(carouselId);
  }
}
```

## 9. Error Handling & Edge Cases

| Scenario | Handling |
|----------|----------|
| Brand DNA not found | Return 404 with clear message |
| Content idea not found | Return 404 |
| AI response exceeds char limit | Auto-truncate with `...` suffix |
| AI returns invalid JSON | Use `validateAiResponse` with repair attempts |
| AI generation fails | Mark job as FAILED, return error to user |
| Forbidden terms detected | Post-process: scan output and flag/warn |
| Multiple platforms fail | Return partial results with failure reasons |
| Rate limiting | Queue via GenerationJob, return job ID for polling |
