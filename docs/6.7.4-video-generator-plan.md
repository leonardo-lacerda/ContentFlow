# Fase 6.7.4 — Short Video Generator: Implementation Plan

> **Goal:** Transform an approved carousel into a short-form video (Reels/TikTok/Shorts) with scene-by-scene script, optional simple animated slides, and optional provider-based video generation. Track cost and status via `GenerationJob`. Start with script/storyboard only, then optional video rendering.

---

## 0. Design Principles

| Principle | Rationale |
|-----------|-----------|
| **Carousel → Video Script** | Approved carousels already have structured slides (headline, body, CTA, images). The video script is a direct transformation: slides become scenes with timing, transitions, and visual notes. |
| **Script first, video optional** | The primary output is a text-based storyboard/script. Video generation is expensive and slow — only triggered via explicit opt-in after cost display. |
| **Reuse GenerationJob** | Video rendering is a job: create a `VIDEO_GENERATION` type in `GenerationJobType`, use existing status/result/costEstimate tracking. No new DB model needed for jobs. |
| **Reuse existing video providers** | The `VideoManager` + `VideoAbstract` infrastructure already supports `image-text-slides` and `veo3`. The short video generator can dispatch to these providers. |
| **Simple motion first** | Start with Ken Burns effect (pan/zoom on images), crossfade transitions, and text overlays. No UGC/influencer generation yet. |
| **Cost transparency** | Before triggering video rendering, show estimated cost (based on provider pricing, scene count, duration). User must explicitly confirm. |
| **New DB model: `ShortVideoProject`** | Stores the script/storyboard, links to CarouselProject, holds video metadata and render status. Separate from GenerationJob for query flexibility. |

```typescript
import { z } from 'zod';

export const VERSION = '1.0.0';

// ---- Sub-schemas ----

const TransitionSchema = z.enum([
  'cut',           // Instant cut
  'crossfade',     // Smooth fade between scenes
  'slide-left',    // Slide transition left
  'slide-right',   // Slide transition right
  'zoom-in',       // Zoom into next scene
  'zoom-out',      // Zoom out to next scene
]).describe('Transition type between scenes');

const TextOverlaySchema = z.object({
  text: z.string().describe('Text to display on screen'),
  position: z.enum(['top', 'center', 'bottom']).default('center').describe('Text position on screen'),
  style: z.enum(['bold', 'subtitle', 'caption', 'hook']).default('subtitle').describe('Visual style of text'),
  durationSec: z.number().min(0.5).describe('How long the text is visible'),
  animation: z.enum(['fade-in', 'slide-up', 'typewriter', 'pop']).default('fade-in').describe('Text animation style'),
});

const SceneSchema = z.object({
  index: z.number().int().min(0).describe('Zero-based scene index'),
  durationSec: z.number().min(1).max(60).describe('Scene duration in seconds'),
  headline: z.string().describe('Main text/headline for this scene'),
  body: z.string().optional().describe('Body text or subtitle'),
  voiceoverText: z.string().optional().describe('Narration/voiceover text for this scene'),
  imagePrompt: z.string().optional().describe('AI image generation prompt (if no carousel image)'),
  imageUrl: z.string().optional().describe('Existing carousel image URL to use'),
  transition: TransitionSchema.default('crossfade').describe('Transition to next scene'),
  textOverlays: z.array(TextOverlaySchema).default([]).describe('Text overlays for this scene'),
  motionNotes: z.string().optional().describe('Visual motion direction (e.g. "slow zoom into center")'),
  musicCue: z.string().optional().describe('Music/sound cue for this scene'),
});

// ---- Main schema ----

export const ShortVideoScriptSchema = z.object({
  title: z.string().describe('Video title'),
  platform: z.string().describe('Target platform (Reels, TikTok, Shorts)'),
  format: z.string().describe('Video format (REELS, TIKTOK, SHORTS, STORIES)'),
  aspectRatio: z.string().default('9:16').describe('Aspect ratio'),
  language: z.string().describe('Language code (e.g. pt-BR, en-US)'),
  totalDurationSec: z.number().min(5).max(180).describe('Total video duration in seconds'),
  scenes: z.array(SceneSchema).min(1).max(30).describe('Scenes in order'),
  scriptNotes: z.string().optional().describe('Overall direction/notes for the video'),
  musicStyle: z.string().optional().describe('Suggested music style/mood'),
  cta: z.string().optional().describe('Call-to-action for the video'),
});

export type ShortVideoScript = z.infer<typeof ShortVideoScriptSchema>;
export type VideoScene = z.infer<typeof SceneSchema>;
export type TextOverlay = z.infer<typeof TextOverlaySchema>;

export function validate(data: unknown): {
  success: boolean;
  data: ShortVideoScript | null;
  errors: z.ZodError | null;
} {
  const result = ShortVideoScriptSchema.safeParse(data);
  if (result.success) {
    return { success: true, data: result.data, errors: null };
  }
  return { success: false, data: null, errors: result.error };
}

export function parse(data: unknown): ShortVideoScript {
  return ShortVideoScriptSchema.parse(data);
}
```

#### File: `libraries/nestjs-libraries/src/database/prisma/short-video/short-video.service.ts`

```typescript
import { Injectable, Logger } from '@nestjs/common';
import { ShortVideoRepository } from './short-video.repository';
import { ShortVideoStatus, ShortVideoFormat, GenerationJobType } from '@prisma/client';
import { GenerationJobService } from '../generation-jobs/generation-job.service';
import { AiGenerateService } from '../../ai-generate/ai-generate.service';
import { validateAiResponse, buildAiMetadata } from '../../ai-generate/ai-response-validator';
import { getSchema } from '../../ai-generate/schemas';
import { CarouselProjectService } from '../carousel-projects/carousel-project.service';

@Injectable()
export class ShortVideoService {
  private readonly logger = new Logger(ShortVideoService.name);

  constructor(
    private shortVideoRepository: ShortVideoRepository,
    private generationJobService: GenerationJobService,
    private aiGenerateService: AiGenerateService,
    private carouselProjectService: CarouselProjectService,
  ) {}

  async getProjects(orgId: string) {
    return this.shortVideoRepository.findByOrganization(orgId);
  }

  async getProjectsByBrand(brandProfileId: string, status?: ShortVideoStatus) {
    return this.shortVideoRepository.findByBrandProfile(brandProfileId, status);
  }

  async getProject(id: string) {
    return this.shortVideoRepository.findById(id);
  }

  async createProject(data: {
    organizationId: string;
    brandProfileId: string;
    carouselProjectId: string;
    contentIdeaId?: string;
    name: string;
    format?: ShortVideoFormat;
    maxDurationSec?: number;
    aspectRatio?: string;
  }) {
    return this.shortVideoRepository.create(data);
  }

  async generateScript(
    projectId: string,
    options: {
      language?: string;
      targetDurationSec?: number;
      style?: string;
    } = {}
  ) {
    const project = await this.shortVideoRepository.findById(projectId);
    if (!project) throw new Error('Short video project not found');

    const carousel = await this.carouselProjectService.getProject(project.carouselProjectId);
    if (!carousel) throw new Error('Carousel project not found');

    // Create generation job
    const job = await this.generationJobService.createJob({
      organizationId: project.organizationId,
      brandProfileId: project.brandProfileId,
      carouselProjectId: project.carouselProjectId,
      type: 'VIDEO_SCRIPT' as any,
      model: 'gpt-4o',
      provider: 'openai',
      promptVersion: '1.0.0',
      schemaVersion: '1.0.0',
      idempotencyKey: `video-script-${projectId}-${Date.now()}`,
    });

    await this.generationJobService.startJob(job.id);

    try {
      // Build prompt from carousel slides
      const slides = carousel.slides as any[];
      const prompt = this.buildScriptPrompt(slides, {
        format: project.format || 'REELS',
        maxDuration: options.targetDurationSec || project.maxDurationSec || 60,
        language: options.language || 'pt-BR',
        style: options.style,
        title: carousel.title,
      });

      // Generate via OpenAI structured output
      const rawResponse = await this.aiGenerateService.generateStructuredOutput(
        prompt,
        getSchema('short-video-script')
      );

      // Validate response
      const validated = validateAiResponse(rawResponse, 'short-video-script');

      // Calculate cost
      const scriptCost = this.estimateScriptCost(slides.length, validated.data?.scenes?.length || 0);

      // Update project
      await this.shortVideoRepository.update(projectId, {
        script: validated.data,
        totalDurationSec: validated.data?.totalDurationSec,
        status: 'SCRIPT_GENERATED',
        scriptCostEstimate: scriptCost,
        totalCostEstimate: scriptCost + (project.renderCostEstimate || 0),
      });

      // Complete job
      await this.generationJobService.completeJob(job.id, validated.data, {
        inputTokens: prompt.length / 4,
        outputTokens: JSON.stringify(validated.data).length / 4,
      });

      return {
        script: validated.data,
        jobId: job.id,
        costEstimate: scriptCost,
      };
    } catch (error) {
      await this.generationJobService.failJob(job.id, error.message);
      await this.shortVideoRepository.updateStatus(projectId, 'FAILED');
      throw error;
    }
  }

  async estimateRenderCost(projectId: string, provider: string, voiceId?: string) {
    const project = await this.shortVideoRepository.findById(projectId);
    if (!project || !project.script) throw new Error('Script not generated yet');

    const script = project.script as any;
    const sceneCount = script.scenes?.length || 0;
    const duration = project.totalDurationSec || 60;

    // Cost estimation based on provider
    const estimates: Record<string, { baseCost: number; perSceneCost: number; perSecondCost: number }> = {
      'image-text-slides': {
        baseCost: 0.02,      // Transloadit base
        perSceneCost: 0.01,  // Image generation per scene
        perSecondCost: 0.005, // Audio processing
      },
      'veo3': {
        baseCost: 0.10,
        perSceneCost: 0.15,
        perSecondCost: 0.02,
      },
    };

    const est = estimates[provider] || estimates['image-text-slides'];
    const cost = est.baseCost + (sceneCount * est.perSceneCost) + (duration * est.perSecondCost);

    // Add voice cost if voiceover
    const hasVoiceover = script.scenes?.some((s: any) => s.voiceoverText);
    const voiceCost = hasVoiceover ? duration * 0.003 : 0; // ~$0.003/sec for ElevenLabs

    const totalCost = cost + voiceCost;

    await this.shortVideoRepository.update(projectId, {
      renderCostEstimate: totalCost,
      renderProvider: provider,
      totalCostEstimate: (project.scriptCostEstimate || 0) + totalCost,
    });

    return {
      provider,
      estimatedCostUsd: Math.round(totalCost * 10000) / 10000,
      voiceCost,
      breakdown: {
        baseCost: est.baseCost,
        sceneCost: sceneCount * est.perSceneCost,
        durationCost: duration * est.perSecondCost,
        voiceCost,
      },
    };
  }

  async renderVideo(
    projectId: string,
    options: {
      provider: string;
      voiceId?: string;
      musicStyle?: string;
      includeSubtitles?: boolean;
      maxCostUsd?: number;
    }
  ) {
    const project = await this.shortVideoRepository.findById(projectId);
    if (!project) throw new Error('Short video project not found');
    if (!project.script) throw new Error('Script not generated yet');
    if (project.status !== 'SCRIPT_GENERATED' && project.status !== 'FAILED') {
      throw new Error(`Cannot render in status: ${project.status}`);
    }

    // Cost check
    const costEstimate = await this.estimateRenderCost(projectId, options.provider, options.voiceId);
    if (options.maxCostUsd && costEstimate.estimatedCostUsd > options.maxCostUsd) {
      throw new Error(`Estimated cost ($${costEstimate.estimatedCostUsd}) exceeds max ($${options.maxCostUsd})`);
    }

    // Create render job
    const job = await this.generationJobService.createJob({
      organizationId: project.organizationId,
      brandProfileId: project.brandProfileId,
      carouselProjectId: project.carouselProjectId,
      type: 'VIDEO_GENERATION' as any,
      model: options.provider,
      provider: options.provider,
      promptVersion: '1.0.0',
      schemaVersion: '1.0.0',
      costEstimate: costEstimate.estimatedCostUsd,
      idempotencyKey: `video-render-${projectId}-${Date.now()}`,
    });

    await this.shortVideoRepository.update(projectId, {
      status: 'RENDERING',
      renderJobId: job.id,
    });

    await this.generationJobService.startJob(job.id);

    // Note: Actual rendering is async. The job status will be updated
    // by a worker/poller. For now, we create the job and return.
    // The frontend will poll the job status.

    return {
      jobId: job.id,
      status: 'RENDERING',
      costEstimate: costEstimate.estimatedCostUsd,
      message: 'Video rendering started. Check the Jobs page for progress.',
    };
  }

  async updateRenderResult(jobId: string, videoUrl: string, thumbnailUrl?: string) {
    // Called by the render worker when done
    const job = await this.generationJobService.getJob(jobId);
    if (!job) return;

    // Find the associated ShortVideoProject
    const projects = await this.shortVideoRepository.findByOrganization(job.organizationId);
    const project = projects.find((p: any) => p.renderJobId === jobId);
    if (!project) return;

    await this.shortVideoRepository.update(project.id, {
      status: 'COMPLETED',
      videoUrl,
      thumbnailUrl,
      renderCostActual: job.costEstimate,
    });
  }

  private buildScriptPrompt(slides: any[], options: {
    format: string;
    maxDuration: number;
    language: string;
    style?: string;
    title: string;
  }): string {
    const slideDescriptions = slides.map((s, i) =>
      `Slide ${i + 1}: Headline: "${s.headline}" | Body: "${s.body}" | CTA: "${s.cta || ''}" | Image: ${s.imagePrompt || 'N/A'}`
    ).join('\n');

    return `Convert this carousel into a ${options.format} short video script.

Carousel title: "${options.title}"
Slides:
${slideDescriptions}

Requirements:
- Target platform: ${options.format}
- Maximum duration: ${options.maxDuration} seconds
- Language: ${options.language}
- Style: ${options.style || 'engaging and professional'}
- Each slide becomes a scene
- Add transition types between scenes
- Include text overlays with timing
- Add voiceover text for each scene (if suitable)
- Add motion notes (zoom, pan, etc.)
- Keep scenes between 2-8 seconds each
- Total scenes should fit within maxDuration
- End with CTA scene

Output a valid ShortVideoScript JSON.`;
  }

  private estimateScriptCost(slideCount: number, sceneCount: number): number {
    // Approximate cost for GPT-4o structured output
    const inputTokens = slideCount * 100;  // ~100 tokens per slide description
    const outputTokens = sceneCount * 150; // ~150 tokens per scene
    const costPer1kInput = 0.0025;
    const costPer1kOutput = 0.01;
    return (inputTokens / 1000) * costPer1kInput + (outputTokens / 1000) * costPer1kOutput;
  }
}
```

## 7. Cost Estimation

### Script Generation (one-time per project)
| Component | Cost | Notes |
|-----------|------|-------|
| GPT-4o input | ~$0.0003 | ~300 tokens for carousel description |
| GPT-4o output | ~$0.0015 | ~150 tokens per scene × scenes |
| **Total script** | **~$0.002** | Negligible |

### Video Rendering (per render attempt)
| Provider | Base | Per Scene | Per Second | Voice | Total (10 scenes, 60s) |
|----------|------|-----------|------------|-------|------------------------|
| image-text-slides | $0.02 | $0.01 | $0.005 | $0.18 | **~$0.52** |
| veo3 | $0.10 | $0.15 | $0.02 | $0.18 | **~$1.58** |

**Note:** Costs are estimates. Actual costs depend on:
- Image generation provider (Fal.ai pricing varies)
- ElevenLabs voice pricing (character-based)
- Transloadit video processing (minute-based)
- Video provider pricing (Veo3 is pay-per-use)

### Cost Display to User
The frontend shows:
1. **Script cost** (always shown after generation)
2. **Estimated render cost** (shown before confirming render)
3. **Cost breakdown** (base + scenes + duration + voice)
4. **Hard cost cap** (user can set `maxCostUsd` before rendering)
