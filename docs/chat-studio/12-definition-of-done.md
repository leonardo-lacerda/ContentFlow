# 12 — Definition of Done

## 1. Definition of Done de uma subfase

Uma subfase só é entregue quando:

- código ou documentação prevista existe no local definido;
- contratos estão versionados;
- testes relevantes passam;
- autorização foi validada;
- estados de erro foram tratados;
- logs não expõem segredos;
- métricas estão instrumentadas quando aplicável;
- documentação de operação foi atualizada;
- produto aprovou o comportamento visível;
- não existem bloqueios conhecidos sem responsável.

## 2. Definition of Done de uma capacidade

Uma capacidade — por exemplo, carrossel ou vídeo — só é entregue quando:

- pode ser iniciada pelo chat;
- possui intenção classificada;
- possui planner tipado;
- possui artefato renderizado;
- possui revisão conversacional;
- possui versionamento;
- possui quote quando há custo;
- possui job assíncrono quando necessário;
- possui retry e cancelamento;
- possui provenance;
- possui autorização e isolamento;
- possui teste de sucesso e falha;
- possui exportação ou próximo passo claro.

## 3. Definition of Done do MVP

- usuário novo cria um artefato sem treinamento;
- ideias, copy, roteiro, carrossel e imagem funcionam;
- vídeo tem pelo menos plano e pipeline inicial controlado;
- conversas persistem;
- anexos funcionam;
- Brand DNA básico é aplicado;
- créditos são exibidos antes de gasto;
- nenhuma publicação ocorre sem confirmação;
- modo avançado continua disponível;
- mobile e teclado são suportados;
- segurança por organização foi testada;
- métricas de produto e operação estão ativas.

## 4. Definition of Done do produto completo

- vídeo completo com refinamento conversacional;
- variantes por plataforma;
- atores e vozes com direitos;
- exportação organizada;
- agendamento e publicação;
- memória controlada;
- avaliação de qualidade de IA;
- observabilidade ponta a ponta;
- fallback de provider;
- takedown e auditoria;
- rollback de release;
- documentação para usuário e suporte.

## 5. Gates que bloqueiam lançamento

- cobrança duplicada;
- publicação sem confirmação;
- acesso entre organizações;
- ator ou voz sem direito aprovado;
- perda de artefato ou versão;
- job sem estado terminal ou recuperação;
- output sem provenance;
- erro de segurança crítico;
- fluxo básico exigindo editor avançado.
