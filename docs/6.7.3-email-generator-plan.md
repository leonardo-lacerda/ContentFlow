# Fase 6.7.3 — Email/Newsletter Generator: Implementation Plan

> **Goal:** Generate email campaigns (newsletters, welcome sequences, promotional campaigns) from Brand DNA + approved content. Transform social media content into polished email format with exportable, portable HTML. Users can preview and edit before export.

---

## 0. Design Principles

| Principle | Rationale |
|-----------|-----------|
| **Email ≠ Social posts repurposed** | Emails have fundamentally different structure: `subject`, `preheader`, `HTML body` with inline styles, `CTA buttons`, and must be email-client compatible. Social content needs structural transformation, not just copy-paste. |
| **Portable HTML with inline styles** | Email HTML must work across Gmail, Outlook, Apple Mail. Use HTML tables for layout + inline CSS. No `<style>` blocks, no external stylesheets, no `<link>` tags. All CSS must be inline for maximum compatibility. |
| **Three campaign types** | Newsletter (carousel-based, content digest), Welcome Sequence (multi-email drip), Promotional Campaign (single high-impact email). Each has distinct structure and AI prompt strategy. |
| **Reuse existing infrastructure** | Uses `BrandProfile`, `BrandDnaSnapshot`, `ContentIdea`, `CarouselProject`, `GenerationJob`, `Media`, OpenAI structured output, and `validateAiResponse` — minimal new DB models. |
| **Inline preview + edit** | Frontend renders the generated HTML in an iframe with a content-editable overlay. Users edit content, then re-export. The HTML is the source of truth. |
| **No email sending** | This phase generates email HTML only. Integration with email providers (Mailchimp, SendGrid) is a future phase. |

  alignment: z.enum(['left', 'center', 'right']).default('center'),
  borderRadius: z.number().default(4).describe('Button border radius in px'),
  marginTop: z.number().optional(),
  marginBottom: z.number().optional(),

const EmailCarouselCardSchema = z.object({
  type: z.literal('carousel_card'),
  imageUrl: z.string().url().describe('Card image URL'),
  title: z.string().describe('Card title'),
  summary: z.string().describe('Card summary text'),
  linkUrl: z.string().url().optional().describe('Card click-through URL'),
});

const EmailCarouselBlockSchema = z.object({
  type: z.literal('carousel'),
  cards: z.array(EmailCarouselCardSchema).min(2).max(10).describe('Carousel cards (rendered as horizontal cards in email)'),

  marginTop: z.number().optional(),
  marginBottom: z.number().optional(),
});

const EmailSpacerBlockSchema = z.object({
  type: z.literal('spacer'),
  height: z.number().default(20).describe('Spacer height in px'),
});

const EmailSocialLinksBlockSchema = z.object({
  type: z.literal('social_links'),
  networks: z.array(z.object({
    name: z.string().describe('Network name (e.g., instagram, twitter, linkedin)'),
    url: z.string().url(),
    icon: z.string().optional().describe('Icon URL or icon name'),
  })).describe('Social media links to display'),
  alignment: z.enum(['left', 'center', 'right']).default('center'),
  marginTop: z.number().optional(),
  marginBottom: z.number().optional(),
});

const EmailBlockSchema = z.discriminatedUnion('type', [
  EmailTextBlockSchema,
  EmailHeadingBlockSchema,
  EmailImageBlockSchema,
  EmailDividerBlockSchema,
  EmailCtaBlockSchema,
  EmailCarouselBlockSchema,
  EmailSpacerBlockSchema,
  EmailSocialLinksBlockSchema,
]);

// ---- Main email campaign schema ----

export const EmailCampaignSchema = z.object({
  type: z.enum(['NEWSLETTER', 'WELCOME_SEQUENCE', 'PROMOTIONAL']).describe('Campaign type'),
  name: z.string().describe('Campaign name for internal reference'),

  subject: z.string().min(1).max(150).describe('Email subject line'),
  preheader: z.string().max(150).optional().describe('Preheader text (shown in inbox preview)'),

  blocks: z.array(EmailBlockSchema).min(3).describe('Email body blocks (ordered top to bottom)'),

  // CTA at email level
  ctaText: z.string().optional().describe('Primary CTA text'),
  ctaUrl: z.string().url().optional().describe('Primary CTA URL'),
  ctaColor: z.string().optional().describe('Primary CTA color hex'),

  // Welcome sequence specific
  sequenceIndex: z.number().int().nonnegative().optional().describe('Position in welcome sequence (0-based)'),
  sequenceTotal: z.number().int().positive().optional().describe('Total emails in sequence'),
  sequenceDelayDays: z.number().int().nonnegative().optional().describe('Days delay before sending'),

  // Visual customization
  headerImageUrl: z.string().url().optional().describe('Header/banner image URL'),
  logoUrl: z.string().url().optional().describe('Logo image URL'),
  primaryColor: z.string().optional().describe('Brand primary color hex'),
  secondaryColor: z.string().optional().describe('Brand secondary color hex'),

  // Generation metadata
  tone: z.string().optional().describe('Tone used for generation'),
  rationale: z.string().optional().describe('Why this approach was chosen'),
  notes: z.string().optional().describe('Internal notes'),
});

export type EmailCampaign = z.infer<typeof EmailCampaignSchema>;

// ---- Batch schema for welcome sequences ----

export const WelcomeSequenceSchema = z.object({
  emails: z.array(EmailCampaignSchema).min(2).max(7).describe('Welcome sequence emails (ordered by sequenceIndex)'),
});

export type WelcomeSequence = z.infer<typeof WelcomeSequenceSchema>;

// ---- Validation helpers ----

export function validateEmail(data: unknown): {
  success: boolean;
  data: EmailCampaign | null;
  errors: z.ZodError | null;
} {
  const result = EmailCampaignSchema.safeParse(data);
  if (result.success) {
    return { success: true, data: result.data, errors: null };
  }
  return { success: false, data: null, errors: result.error };
}

export function parseEmail(data: unknown): EmailCampaign {
  return EmailCampaignSchema.parse(data);
}

This module converts the structured `EmailCampaign` (with `blocks[]`) into portable, inline-styled HTML that works across email clients.

**Key design decisions:**
- All CSS is **inline** — no `<style>` blocks, no `class` attributes
- Layout uses **HTML tables** (not flexbox/grid) for Outlook compatibility
- Max width: 600px (standard email width)

      brandProfileId: dto.brandProfileId,
      contentIdeaId: dto.contentIdeaId,
      carouselProjectId: dto.carouselProjectId,
      type: dto.type,
      name: `${template.label} - ${new Date().toLocaleDateString('pt-BR')}`,
      subject: aiResult.subject,
      preheader: aiResult.preheader,
      bodyHtml: html,
      bodyJson: { blocks: aiResult.blocks },

      primaryColor: aiResult.primaryColor,
